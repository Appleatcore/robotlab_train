结论

当前版本已经不是“小修小补”，而是从原始的 无高程图 policy + 更保守的 reward 基线，演化成了 带高程图输入 + 更温和 reset + 接触质量/执行平滑/非法接触约束 的训练分支。

主变化

最大变化集中在五块：height_scan、动作尺度、reset 分布、reward 重构、illegal_contact 启用。

风险点

radar_link_name 在当前文件里被新增但未实际使用；usd_dir=/tmp/IsaacLab_ycl/unitree_go2w 也是环境相关改动，迁移机器时要额外注意。

  • 原始版本更接近“不依赖地形前瞻”的控制基线。

  • 如果 reward 没有同步给出足够的越障正激励，高程图会把策略推向“保守但安全”的局部最优。

  • 当前版本把训练分布收窄，更像“把能力集中在运动控制和越障细节”上。
  • 这通常会让前期课程更稳，但也会减少对极端姿态恢复的覆盖。

Reward 结构变化的核心逻辑

  • 原始版本整体上更像：强 tracking、强默认姿态约束、无感知 policy。
  • 当前版本更像：弱化硬性的姿态/能耗/镜像约束，加入 perception 后补上接触质量和摆腿高度项。
  • 这说明当前分支的目标，不再只是“平地把速度跟住”，而是开始兼顾“看到台阶后的行为质量”。

4. 当前版本最重要的几类行为改变

4.1 从“速度主导”变成“速度 + 接触质量 + 摆腿”混合主导

原始版本里 track_lin_vel_xy_exp=3.0、track_ang_vel_z_exp=1.5， 同时 feet_stumble、feet_slide、wheel_vel_penalty 都没有真正介入。 当前版本则把 tracking 拆成粗细两层，并开始引入接触质量和摆腿高度塑形。

这意味着当前版本更容易学到“前进不能只看速度，还要少踢阶、少滑脚、摆腿更合适”。

4.2 从“强默认位姿约束”变成“允许更多越障动作”

joint_pos_penalty 从 -1.0 降到 -0.15， joint_pos_limits 从 -5.0 降到 -2.0， joint_mirror 从 -0.05 降到 -0.005。

这些变化整体是在告诉策略：为了越障，可以接受更大的腿部偏离和更不那么“教科书式对称”的动作。

4.3 但同时又引入了“看见风险就保守”的潜在诱因

当前版本打开了 height_scan，并新增：

  • feet_stumble=-0.1
  • feet_slide=-0.05
  • wheel_vel_penalty=-0.0020
  • illegal_contact(base, threshold=20.0)

这会让策略更清楚地意识到“大高度落差是危险的”。如果正向越障激励不够强，它就可能学出“停住比硬上更划算”的保守解。

5. 终止条件变化

项 原始版本 当前版本 分析
illegal_contact 关闭 启用，监控 base，阈值 20.0 当前版本开始把 base 撞击纳入提前终止逻辑。这通常会减少“趴着硬顶台阶”的样本，但也会增加策略的保守性。

6. 综合判断

总体结论

  • 原始版本是一个更典型的 rough locomotion 基线：不让 policy 看高程图，tracking 权重大，默认姿态和限位约束较重，非法接触关闭。
  • 当前版本已经明显转向“感知参与控制”的楼梯/越障训练分支。
  • 当前参数组合的设计思路是合理的：打开高程图、弱化一部分过硬的姿态约束、补上接触质量项和轻量摆腿高度项。
  • 但它也天然更容易出现“看见危险后停止前进”的局部最优，因为当前分支已经把风险信息和风险惩罚都补上了。

我认为最值得关注的三处

  • 最结构性的变化： policy.height_scan 从关闭变成开启，并做了 height_scan_norm。
  • 最容易解释行为变化的变化： illegal_contact 启用 + feet_stumble / feet_slide 从 0 变为负值。
  • 最能改变腿部越障自由度的变化： joint_pos_penalty、joint_pos_limits、joint_mirror 的放松，以及 feet_height_body 的引入。

一个额外提醒

当前版本里 radar_link_name = "radar" 被加进来了，但这份配置文件没有实际用它去绑定扫描器。 真正决定高程图展开位置的仍然是：

self.scene.height_scanner.prim_path = "{ENV_REGEX_NS}/Robot/" + self.base_link_name

所以就这份文件本身来看，当前高程图仍然是从 base link 展开的，不是从 radar link 展开。
