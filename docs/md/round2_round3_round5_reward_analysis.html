Round 2 / Round 3 / Round 5 奖励与训练项分析

基于 README_go2w_cusrl_mirlab_borrow_plan.md 的实验计划， 结合 rough_env_cfg.py、velocity_env_cfg.py 与 mdp/rewards.py 的实际实现整理。

总公式

环境每步回报可以抽象成：

R_t = Σ_i w_i * φ_i(s_t, a_t)

其中 w_i 是权重，φ_i 是某个 reward term 的实际计算值。 w_i > 0 表示鼓励，w_i < 0 表示惩罚。

Round 2: 接触质量相关惩罚

Round 2 的主题不是“主动抬腿奖励”，而是把坏的接触行为罚得更明显： 少空转、少踢台阶、少滑脚。

项 公式 权重变化 具体含义
wheel_vel_penalty
if moving: φ = Σ_i 1_air(i) * |qdot_i| else: φ = Σ_i |qdot_i|
 -5e-4 -> -0.0015 惩罚轮子在离地时还高速转动，也惩罚静止时轮子乱转。 本质是在压制“空转”和无效轮速。
feet_stumble
φ = 1[∃ foot_i, ||F_xy(i)|| > 4 * |F_z(i)|] * g
 -0.02 -> -0.1 当脚与近似竖直表面发生“横向撞击”时触发， 典型场景就是踢到台阶立面。 惩罚更大后，策略会更倾向避免“直接踢阶”。
feet_slide
φ = Σ_i 1_contact(i) * ||v_foot_body_xy(i)|| * g
 -0.02 -> -0.05 只在脚接触地面时统计，惩罚着地后的横向滑动。 它会推动脚着地点更稳，减少“拖着脚蹭过去”的行为。

Round 2 的整体作用

  • 不是直接奖励“抬腿更高”，而是惩罚差的接触模式。
  • 如果这些惩罚太强，而没有对应的摆腿正激励，策略可能学成“更保守”。
  • 因此这轮更像接触质量修正，而不是过台阶能力的直接塑形。

Round 3: 双层速度跟踪

Round 3 的重点是把单一的速度跟踪拆成“粗 tracking + 细 tracking”两层， 让上楼时机身速度更规整，而不是只有大方向上差不多就行。

项 公式 权重 具体含义
track_lin_vel_xy_exp
φ = exp( - ||v_cmd_xy - v_body_xy||² / std² ) * g std = 0.5
 1.5 粗粒度线速度跟踪。只要机身速度整体方向和大小比较接近指令，就能拿到较高奖励。
track_lin_vel_xy_exp_fine
φ = exp( - ||v_cmd_xy - v_body_xy||² / 0.2² ) * g
 1.0 细粒度线速度跟踪。因为 std 更小，误差稍大时奖励会掉得更快， 所以它更强调“精确贴着指令跑”。
track_ang_vel_z_exp
φ = exp( - (ω_cmd_z - ω_body_z)² / std² ) * g
 1.0 约束偏航角速度跟踪，避免楼梯过程中转向和姿态控制发散。

Round 3 的整体作用

  • 不是增加碰撞类惩罚，而是加强“按命令稳定前进”的回报结构。
  • 相比单独把 track_lin_vel_xy_exp 权重拉很高，双层 tracking 更不容易让 reward 被单一速度项主导。
  • 对楼梯行为来说，这一轮更偏“速度品质”和“机身运动规整性”。

Round 5: 主要不是奖励轮

Round 5 在文档里叫“借 MIRLab 的 CusRL hooks”，改的是 trainer hooks， 而不是环境里的 reward term。

关键点： Round 5 严格说不是奖励设计轮。它主要影响的是训练稳定性、输入分布和数据利用方式， 而不是直接改环境回报函数。
Hook 近似公式/机制 含义
ObservationNormalization()
obs_norm = (obs - mean) / (std + eps)
 归一化观测，减少不同量纲和不同数值范围对 PPO 优化的干扰。 这会改变策略“看到”的输入分布，但不是 reward。
SymmetricDataAugmentation()
利用左右镜像样本扩充 on-policy 数据
 让策略更容易学到左右对称的动作模式，提高样本利用效率。 它不改环境打分规则。
EntropyLoss(weight=0.01)
L_entropy = -β * H(π), β = 0.01
 这是训练目标中的熵正则，用来保持探索，防止策略过早塌缩。 它也不是环境 reward，而是优化器里的附加损失项。

Round 5 的整体作用

  • 让训练过程更稳，不是让环境“直接更奖励抬腿”。
  • 如果前面 reward 本身就把策略推向保守，Round 5 最多是更稳定地学到这个保守解。
  • 所以 Round 5 解决的是“怎么学”，不是“学什么”。

三轮对照结论

轮次 主要改动类型 更偏向解决什么问题 局限
Round 2 接触类惩罚更强 减少踢阶、滑脚、空转 不直接奖励“主动抬腿”
Round 3 速度跟踪更分层 让上楼时的机身速度更规整、更贴指令 不直接塑形脚的越障高度
Round 5 trainer hooks 提升训练稳定性和样本效率 本质上不是 reward 修改

一句话判断

如果你的目标是“机器人看到大高度差后主动抬腿上楼”， 那么 Round 2 更像是在罚坏接触，Round 3 更像是在修速度品质， Round 5 更像是在修训练流程； 它们都不是最直接的“抬腿高度塑形”项。
